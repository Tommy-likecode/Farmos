# Farmos M11 glossy continuation test fixtures

Sources use the M1 TypeScript-style surface, M2 math, M3/M4 scene + path API,
M7/M8/M9 backends, and M11 glossy continuation controls. See
`spec/M11-glossy-continuation.md` (**FINAL** — OQ-M11-01..08 all A). Do not edit
M1–M10 milestone bodies to absorb these rules; amendments live in
`M11-glossy-continuation.md`.

This file documents **M11-only** notes. It does not replace `spec/tests/README.md`
or prior milestone READMEs. Harness kinds `run`, `runtime_trap`, `run_png` keep
their M1/M3/M4/M7 meanings. Prior headers `# requires_vulkan:`,
`# requires_vulkan_rt:`, `# png_tol:`, `# env:`, `# path_mode:` remain valid.

## Layout

```
spec/tests/M11/
  README.md
  NNN_name.fm
  NNN_name.expected
  bench/                     (artwork ROI notes)
  _ref/
    README.md
```

CPU compat goldens (glossy OFF) reuse M4 SHA values (copy from M4/M7/M8/M9
twins). Glossy-ON fixtures use `# png_tol:` or smoke goldens regenerated by
poteto.

## Working directory

The harness MUST run each M11 program with CWD = `spec/tests/M11`.
`savePNG("out.png")` writes `spec/tests/M11/out.png`.

## Soft-skip

| Header | When to soft-skip |
|--------|-------------------|
| `# requires_vulkan: true` | No usable Vulkan **compute** device (M7) |
| `# requires_vulkan_rt: true` | No usable Vulkan **hardware RT** (M9) |

Soft-skip: do **not** fail; log skip; runner exit 0 for that case.

Linux CI without GPU: keep glossy-OFF CPU twins and API/trap fixtures green;
soft-skip GPU/RT ROI benches.

## Artwork ROI bench

- Scene: `examples/artwork_silver_still.fm` @ 1920×1080 preferred; `metalness=1`,
  `roughness=0.04`, RectAreaLights only — **do not** brighten env/lights; **do not**
  set roughness 0 for the product AC.
- ROI: 40×40 ball-center (CLAIM: `x=940:980,y=520:560` on 1080p).
- OFF: mean L ≤ **5** (CLAIM 0.00).
- ON: mean L ≥ **80** (target order ~v1 **106.31**); spp ≥64 (256 preferred).
- Backends: CPU / VULKAN / VULKAN_RT when available.
- Scripts under `spec/tests/M11/bench/`.

Stopgap `setRoughness(0)` restores Oct-14 v1 ball L=**106.310** exactly but is
**not** the product fix.
