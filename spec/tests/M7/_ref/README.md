# M7 reference notes

CPU `run_png` fixtures twin M4 scenes and reuse SHA-256 values from
`spec/tests/M4/_ref/goldens_sha256.txt` (copied into `goldens_sha256.txt` here
for convenience).

GPU fixtures compare against the same CPU golden with `# png_tol: 2` unless a
separate GPU golden is introduced later.

This directory does **not** contain product code.
